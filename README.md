# Deutschwerk 🇩🇪

**The complete German learning platform — from A1 to B2, with Goethe & TELC exam preparation.**

Deutschwerk is a production-ready, full-stack web application where learners study German from complete beginner to upper-intermediate without needing any external resource: structured CEFR courses, grammar, vocabulary, spaced-repetition flashcards, all four skills, timed mock exams, printable PDFs, social learning and an Ausbildung career track.

## ✨ Features

| Area | What's inside |
|---|---|
| **Courses A1–B2** | 9 modules · 28 seeded lessons with dialogues, tables, culture notes, homework, revision, mini-tests — content model scales to C1/C2 with zero code changes |
| **Grammar** | 20 topics with simple + detailed explanations, tables, examples, common mistakes, cheat sheets, attached practice & printable sheets |
| **Vocabulary** | 283 curated words in 14 topic packs — article, plural, IPA, examples, synonyms, opposites, expressions, memory tips |
| **Flashcards** | Full SM-2 spaced repetition: due queue, interval previews, favorites, decks, retention stats, Anki-compatible CSV export |
| **Four skills** | Reading library with glossaries & grammar highlights · Listening studio with real TTS audio, transcripts & speed control · Speaking with roleplay mode & microphone recorder · Writing with AI-assisted corrections + native sample answers |
| **Pronunciation** | Alphabet, umlauts, difficult sounds, minimal pairs, common mistakes — every word speakable via device TTS |
| **Dictionary & verbs** | Searchable word base + 63 verbs with complete conjugation tables (Präsens → Konjunktiv II → Passiv), generated by a built-in conjugation engine |
| **Exam prep** | 4 timed mock exams in authentic Goethe/TELC format with auto-scoring, section breakdowns, answer review & printable papers · format guides & strategies per level |
| **Ausbildung track** | German CV & Anschreiben templates, the 8 standard interview questions with model answers, workplace vocabulary by field, phone/email phrases, work culture |
| **PDF Library** | Every lesson, grammar sheet, vocab list, reading and exam as a professionally formatted print view (browser → Save as PDF) |
| **Progress** | XP, streaks, daily goals, calendar heatmap, per-skill scores, weak/strong areas, achievements, level certificates |
| **Social** | Study groups with invite codes, group chat, weekly progress comparison, challenges, leaderboards, discussion forum |
| **Platform** | Auth with email verification & password reset, profiles with avatar upload, rich-text notes with folders, bookmarks, study planner with exam countdown, global ⌘K search, full dark mode, PWA offline support, admin panel |

## 🚀 Quickstart

**Prerequisites:** Node 20+, pnpm, and a PostgreSQL database.

```bash
# 1. Install
pnpm install

# 2. Configure
cp .env.example .env      # then set DATABASE_URL (and a fresh AUTH_SECRET)

# 3. Create schema + seed all content
pnpm db:push
pnpm db:seed

# 4. Run
pnpm dev                  # → http://localhost:3000
```

### Demo accounts (created by the seed)

| Role | Email | Password |
|---|---|---|
| Student (with progress) | `demo@deutschwerk.dev` | `deutschwerk` |
| Admin | `admin@deutschwerk.dev` | `deutschwerk` |

### Database options

- **Local PostgreSQL** — any Postgres 14+; set `DATABASE_URL=postgresql://user:pass@localhost:5432/deutschwerk`
- **Docker** — `docker run -d -p 5432:5432 -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=deutschwerk postgres:16`
- **Supabase** — see [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)

## 🔧 Environment variables

| Variable | Required | Purpose |
|---|---|---|
| `DATABASE_URL` | ✅ | PostgreSQL connection string |
| `AUTH_SECRET` | ✅ | Session encryption — `openssl rand -base64 32` |
| `NEXT_PUBLIC_APP_URL` | ✅ | Public URL (used in emails) |
| `RESEND_API_KEY` | optional | Real verification/reset emails via Resend. Without it, **dev-mail mode** logs links and surfaces them in the UI so all flows stay testable |
| `AI_API_KEY` / `AI_BASE_URL` / `AI_MODEL` | optional | AI writing corrections via any OpenAI-compatible API. Without a key, a built-in rule-based checker + native sample answers keep the feature fully functional |

## 📁 Project structure

```
prisma/
  schema.prisma          # 35+ models: curriculum, progress, SRS, social, gamification
  seed.ts                # idempotent seeder
  seed-data/             # ALL curriculum content lives here (source of truth)
    lessons-a1.ts …      # modules & lessons per level
    grammar-a.ts …       # grammar topics with blocks & cheat sheets
    vocab-a.ts …         # vocabulary packs
    conjugator.ts        # German conjugation engine + verb specs
    exercises-*.ts       # 40 exercises (MCQ / gap / ordering / matching)
    exams.ts             # Goethe & TELC mock exams
    skills-*.ts          # readings, listenings, speakings, writings
src/
  app/
    (auth)/              # login, register, verify, reset
    (app)/               # 38 authenticated pages (dashboard … admin)
    print/               # print-optimized PDF views
    api/                 # 20+ route handlers (all self-authenticating)
  components/
    ui/                  # 22 vendored shadcn-style primitives
    app|content|exercises|exams|…  # feature components
  lib/                   # auth, srs, ai, scoring, activity, conjugation, …
  types/content.ts       # the typed contract for all JSON content
public/audio/            # generated German TTS dialogues (MP3)
```

## ✍️ Adding content

All curriculum lives in `prisma/seed-data/` as typed TypeScript — validated by the compiler against `src/types/content.ts`:

1. Add a lesson/topic/exam to the matching seed file (or a whole new level: add to `levels.ts` + a `lessons-c1.ts`)
2. `pnpm db:seed` — upserts idempotently, existing user progress is preserved
3. For ad-hoc edits: `pnpm db:studio` opens a database GUI
